NLP Disaster Tweet Pipeline

Natural Language Processing · Binary Classification · Kaggle Competition

01
Foundation
Problem Definition
Binary Classification NLP
Given a tweet (with optional keyword & location metadata), predict whether it describes a real disaster (target=1) or not (target=0). Primary metric: F1-score.
Evaluation: F1 · ROC-AUC · Accuracy
Challenge: Sarcasm · Slang · 280 chars
02
Ingestion
Data Loading & Inspection
pandas numpy
Load train.csv (7,613 samples) & test.csv (3,263 samples). Inspect data types, missing values, target distribution. Discover 57%/43% class balance, 61 missing keywords, 2,533 missing locations.
Key insight: Mild imbalance (57/43) — no heavy resampling needed
03
Analysis
Exploratory Data Analysis
matplotlib seaborn wordcloud
Analyze text length, word count, keyword frequency, hashtag patterns, URL presence per class. Generate word clouds per class.
Techniques: Histograms · Bar charts · Pie charts · Word clouds
Discoveries: URLs ~2× more common in disaster tweets
Python pandas matplotlib seaborn
04
Cleaning
Text Preprocessing
nltk re
Multi-stage cleaning pipeline: lowercase → remove URLs & HTML → strip punctuation/digits → remove stopwords (NLTK) → lemmatize (WordNet). Filter words <3 chars.
Technique: Stopword Removal + Lemmatization
Output: Avg 61.8 chars cleaned text
Python NLTK regex
05
Encoding
Feature Engineering — TF-IDF
scikit-learn TfidfVectorizer
Convert text to numerical features using TF-IDF with ngram_range=(1,2) (unigrams + bigrams). Limit to top 5,000 features, ignore rare/common terms (min_df=2, max_df=0.85).
Technique: TF-IDF + N-Grams (1,2)
Vocab size: 5,000 tokens
scikit-learn pandas
06
Training
Model Building
scikit-learn 4 Classifiers
Train & evaluate 4 classifiers on 80/20 stratified split. Compare via confusion matrices, ROC curves, F1 scores.
Models: LogisticRegression · MultinomialNB · RandomForest · LinearSVC
Split: 80/20 · Stratified
LogisticRegression MultinomialNB RandomForest LinearSVC
07
Optimization
Cross-Validation & Hyperparameter Tuning
scikit-learn GridSearchCV
5-fold Stratified CV on best model → best LR: F1 = 0.744 ± 0.010. GridSearchCV over C & solver params. Analyze top TF-IDF coefficients for feature importance.
Best model: LogisticRegression (C=1.0)
CV F1: 0.744 ± 0.010
StratifiedKFold GridSearchCV Coefficient Analysis
08
Production
Generate Test Predictions
pandas CSV
Predict on test set using tuned LogisticRegression. Generate Kaggle-ready submission.csv with id & target columns. Class distribution: 61.3% Not Disaster / 38.7% Disaster.
Output: data/submission.csv
Test preds: 3,263 samples
09
Insights
Conclusion & Insights
F1: 0.744 ROC-AUC: 0.82
Logistic Regression with TF-IDF (unigrams+bigrams) achieves ~0.744 F1. Top disaster signals: hiroshima, wildfire, earthquake. Top non-disaster signals: better, ticket, cake.
Takeaway: LR + TF-IDF is a strong baseline; transformers/embeddings for improvement
