# Module 24: Capstone Projects

**Duration: 32 hours**

## Overview

This capstone module brings together everything you've learned across all previous modules. You will complete one or more of five comprehensive projects that demonstrate mastery of Python for ML, DS, and AI engineering. Each project is designed to be portfolio-ready and showcases different aspects of the ML lifecycle.

## Learning Objectives

By completing these capstone projects, you will be able to:
- Build and deploy end-to-end ML pipelines with experiment tracking
- Design and implement data engineering ETL pipelines with scheduling
- Construct recommendation systems with proper evaluation
- Develop NLP solutions using text processing and ML pipelines
- Deploy production-ready prediction APIs with Docker and testing
- Apply software engineering best practices to ML projects
- Document and present ML projects effectively

## The Five Capstone Projects

| # | Project | Hours | Focus Area |
|---|---------|-------|------------|
| 1 | End-to-End ML Pipeline | 8 | Full ML workflow, experiment tracking |
| 2 | Data Engineering ETL Pipeline | 6 | Data pipelines, orchestration |
| 3 | Recommendation System | 6 | Recommender systems, evaluation metrics |
| 4 | NLP Project | 6 | Text processing, NLP pipelines |
| 5 | Production Prediction API | 6 | Deployment, containerization, testing |

## Evaluation Criteria

All projects will be evaluated on:

- **Correctness**: Does the implementation work as specified?
- **Code Quality**: Is the code clean, modular, and well-documented?
- **Architecture**: Is the project structure organized and maintainable?
- **Testing**: Are critical components tested?
- **Documentation**: Is the project well-documented with clear instructions?
- **Best Practices**: Does it follow ML/software engineering best practices?

## Submission Guidelines

1. Create a GitHub repository for your chosen project
2. Include a README.md with:
   - Project overview and architecture
   - Setup and installation instructions
   - Usage examples
   - Results and evaluation
3. Ensure all code is tested and documented
4. Include any necessary configuration files
5. Add a requirements.txt or pyproject.toml

## Practice Questions

1. How would you design experiment tracking for a project comparing 5 model architectures?
2. What are the trade-offs between batch and streaming ETL pipelines?
3. How do you evaluate a recommendation system when ground truth is implicit feedback?
4. What preprocessing steps are essential for a text classification pipeline?
5. How do you handle model versioning and rollback in a production API?
