# Mini Project: Project Scaffolding Tool

## Problem Statement
Data scientists waste hours setting up new projects. Build a CLI tool that automates project scaffolding for ML/DS projects.

## Requirements
Create a Python script that:
1. Takes a project name as input
2. Creates the directory structure:
   ```
   project_name/
   ├── data/
   │   ├── raw/
   │   └── processed/
   ├── notebooks/
   ├── src/
   │   ├── __init__.py
   │   ├── data/
   │   ├── features/
   │   └── models/
   ├── tests/
   ├── .gitignore
   ├── README.md
   └── requirements.txt
   ```
3. Initializes a git repository
4. Creates a virtual environment
5. Installs base packages (numpy, pandas, matplotlib, scikit-learn, jupyter)
6. Creates a requirements.txt with pinned versions

## Deliverables
- `scaffold.py` — the main script
- Working project generated by your script

## Evaluation Criteria
- ✅ All directories created correctly
- ✅ Virtual environment created and working
- ✅ Packages installable
- ✅ Git repo initialized
- ✅ `.gitignore` contains proper exclusions
- ✅ Clean, documented code with type hints

## Hints
- Use `os.makedirs(exist_ok=True)` for directory creation
- Use `subprocess.run()` to call pip and git
- Handle errors gracefully — what if git isn't installed?
- Make the requirements template a constant at the top of the file
